Cómo completar este formulario

  1. ¿Qué es esto? Raifen está haciendo un relevamiento del negocio para el proyecto de datos — estas preguntas ayudan a entender cómo funciona todo hoy, en la práctica.
  2. Se completa de a poco. No hace falta terminarlo de una sola sentada — cada respuesta se guarda sola apenas se escribe, se puede cerrar la página y volver después con el mismo link.
  3. Se puede hablar en vez de escribir. Las preguntas de texto libre tienen un botón "🎙️ Grabar respuesta en voz" — se transcribe automáticamente y se puede corregir antes de guardar.
  4. "Lo que ya sabemos" es información que Raifen ya tiene del negocio (de conversaciones previas). Si algo ahí no es correcto o está desactualizado, se puede indicar en el campo de correcciones, justo debajo.
  5. Al terminar, el botón "Marcar formulario como finalizado" avisa que ya está listo — pero no bloquea nada, se puede seguir editando después si aparece algo más.
